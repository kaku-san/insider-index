# InsiderIndex Design Rework V2

## Direction

**Consumer social on the surface. Financial credibility underneath.**

Mental model: **Vanguard for famous people, designed by the Instagram/Snapchat generation.** The premise can be witty; the money surfaces cannot feel like a casino or a meme terminal.

## Signature system

1. **People are large.** Editorial photography is a core navigation primitive, not decoration.
2. **Index identity is explicit.** Famous person → person index → public holdings/disclosures.
3. **Performance is narrative.** One dominant curve, restrained comparison grammar, transaction/disclosure markers, direct manipulation.
4. **Holdings are readable before they are analytical.** Company/ticker + ranking + weight bar, then deeper composition.
5. **The paper trail is approachable.** Recent moves read like a social activity feed; source details remain one interaction away.
6. **Sharing is a product surface.** A portfolio should create a story-quality artifact rather than a screenshot of a dashboard.

## Anti-slop rules

- no card around every section
- no glassmorphism or ornamental gradients
- no crypto-neon visual language
- no generic icon-in-colored-square section headings
- no decorative motion on every scroll entrance
- no tiny LinkedIn-style portraits as the main identity
- no database-health metrics as hero content
- no invented financial/social data to make the page feel populated

## Home hierarchy

Hero → featured person index → visual people discovery → recent disclosure tape → directory → short manifesto.

Home is discovery/research. It must not imply that every published model can already be bought as a live fund.

## Person hierarchy

Identity → performance story → holdings → recent moves → source book → four clocks → index state/action.

The person is the hook. The index is the product. Provenance is the trust layer.

## Preview boundary

The offline preview may use clearly labelled design-review fixture data to prevent a blank design review, but those fixtures must never masquerade as production data. Illustrative performance must remain labelled as illustrative in the hero, chart, and share artifact.
