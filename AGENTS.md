Deposits are a **separate per-vault gate** from creation: `depositGate`/`depositsEnabled` (closed by default, opens only at full tradable coverage) with `VAULT_RELEASE.publicFundsEnabled` authoritative on top (`deposits.effectiveEnabled`); columns + the single-row-read GROUP-BY fix are in `supabase/migrations/202609170001_insiderindex_vault_deposits.sql`.
- **Native `update_token_prices` is Raydium-only; zap/eligibility quotes are Raydium then Jupiter.** `raydium-oracles.ts` rejects `oracle_type: "pyth"`, maps `mint → Raydium pool` (never invent one), and builds `update_token_prices` without the SDK's `updateTokenPricesTx` (it always opens a Hermes client). ## Data sources (`src/lib/disclosures/`)

- Insiders: SEC EDGAR primary (`edgar.ts`), Form4API fallback, mocks dev-only.
- Congress: AInvest primary (`ainvest.ts`, `AINVEST_API_KEY`), Form4API fallback, mocks dev-only. AInvest is ticker-scoped (no per-member pull): the crawl universe is `buildCongressUniverse()` in `universe.ts` (`AINVEST_UNIVERSE`).
- `GET /api/disclosures` → `lanes` tells you what actually served; `catalog` says whether venue tags came from the live catalog or the snapshot. The feed body is served from the committed PelosiTracker/FMP bundle via `src/lib/tracker/feed.ts` (through the tracker handoff module, not a second parse) as research-only rows (`source: "pelositracker"`, `tradeEligible: false`, value bands never exact prices); the live EDGAR/AInvest lanes are reported `off` with provenance rather than probed/retried. Payload is paginated (`?page`/`?limit`, documented default/max in `feed.ts`).

## Sharp edges

- Shared caches go through `globalState()` in `src/lib/cache.ts`.
- EDGAR cold crawl ~30 s; warmed at boot via `src/instrumentation.ts`.
- A stale gitignored `.next/` makes `npm run typecheck` fail on deleted routes (`TS2307 … src/app/api/<removed>/route.js` in `.next/types/validator.ts`). It is a cache, not a source error: `rm -rf .next` (or `npm run build`) and re-run. The no-mistakes Test gate runs `npm run typecheck && npm test` (`.no-mistakes.yaml`), so clear it there before trusting a red typecheck.
- Jupiter live vs stub is `jupiterMode()` in `src/lib/runtime.ts`; live mode rejects stub signatures. Wallet fallback (`src/components/providers/privy-provider.tsx`) fails closed in production; a Privy load failure must never enable a fixture wallet.
